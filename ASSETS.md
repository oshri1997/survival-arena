# Asset provenance and production art pipeline

## Original assets

The SVG source and generator in this repository were authored specifically for Survival Arena LIVE. They contain no traced or imported commercial characters. Runtime PNG files are generated by Sharp from those sources.

| Files                                   | Purpose                                                                                               | Provenance                                                                |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `src/assets/arena.svg`                  | Weathered forest cobbles, engraved perspective dais, masonry, roots, ferns, mushrooms and leaf canopy | Original procedural vector illustration                                   |
| `imp`, `skeleton`, `wraith`, `boss`     | Distinct, detailed monster silhouettes with armor, faces, limbs and six-frame movement                | Original path-based character art                                         |
| `crystal`, `guardian`, `torch`, `spark` | Crystal pedestal, emerald mage, braziers and soft particle source                                     | Original vector illustration                                              |
| `src/ui/icons.ts`, `public/favicon.svg` | UI icons and brand mark                                                                               | Original SVG path artwork                                                 |
| `public/fonts/manrope.ttf`              | Interface type                                                                                        | Manrope by Mikhail Sharanda / Manrope Project, SIL OFL 1.1                |
| `public/fonts/cormorant*.ttf`           | Display type                                                                                          | Cormorant Garamond by Christian Thalmann / Cormorant Project, SIL OFL 1.1 |

Original game artwork and UI icon paths are provided under **CC0 1.0 Universal**: https://creativecommons.org/publicdomain/zero/1.0/. This dedication covers only the original art listed here, not third-party fonts or software. Font license notices are included in `public/fonts/`.

## Rebuild or replace

```sh
npm run assets
npm run build
```

`generate-assets.mjs` is deterministic. It writes editable SVGs under `src/assets/` and matching PNGs under `public/assets/`. Monster sheets are six horizontal 96×96 frames; preserve those dimensions and names or update `ArenaScene.preload` and animation setup. Collision sizes live in `game/config.ts` and do not depend on artwork. Images use alpha; keep feet aligned around y=67 for monster depth sorting.

## Honest visual scope

These are finished, original assets for a stylized vector vertical slice, rather than unlicensed stock art or geometric collision-body placeholders. They are not being presented as a complete commercial hand-painted art pack. Movement is six-frame limb/bob animation; attack, death and boss phase-specific sprite clips are not yet authored. Impacts use flash, particles, floating text and removal. Sound effects are synthesized tones, not a recorded sound library.

For commercial art completion, replace or expand the sources with: painted stone/bark/moss materials, richer plant variation, dedicated anticipation/attack/hurt/death clips for all four enemies, a full boss intro and phase transition, mage cast animations, and a mastered ambient music/SFX set. Keep source provenance and licenses beside new assets. Do not substitute copyrighted characters.
