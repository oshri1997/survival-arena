# Survival Arena LIVE

Mobile-first interactive survival game prototype for TikTok LIVE.

## Run
Open `index.html` in a modern browser, or deploy the repository as a static site on Netlify (publish directory: `.`). No build required.

## Features
- Responsive portrait canvas, enemy waves, automatic defense, health and scoring
- Fireball and freeze controls
- Simulated gift test button (not connected to TikTok)

## Roadmap
1. Improve art, animations, audio and balancing
2. Add event adapter with mock and live implementations
3. Integrate a supported TikTok LIVE event provider and test safely
4. Add moderation, dashboard and telemetry

## Safety
This is a demo. No real TikTok account connection, payments, prizes, or revenue tracking are implemented. Supervise any future livestream and comply with platform rules.
